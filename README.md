# QOI Toolkit

My take on writing a Quite OK Image Format (QOI) encoder and decoder from scratch using the Node ecosystem and possibly TypeScript typing at some point.

> **Status: Work in Progress**
> This project is being built in incremental steps. Every commit should be stable and working, but features will be introduced sequentially.
